## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-findprocdll/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `FindProcDLL.dll` to `Plugins/<variant>/`.
